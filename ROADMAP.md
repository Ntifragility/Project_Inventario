# Roadmap & Future Feature Blueprints

This document tracks premium features planned for future sessions to scale the **OT E&I - Materiales** inventory management system.

---

## 1. Visual Mappings Manager (Dynamic SaaS Profile)
Currently, import mappings are defined in the front-end code (`pipelineConfig.js`). The **Visual Mappings Manager** will make this 100% self-serve and dynamic.

### Objectives
- Move configuration arrays (expected columns, mandatory fields, signature columns) to a Supabase table.
- Build an interactive UI step that allows users to map their own Excel columns to the system fields.

### Proposed Database Schema (`import_profiles`)
```sql
CREATE TABLE import_profiles (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(255) UNIQUE NOT NULL, -- e.g., 'Procura Ingresos', 'Almacen Salidas'
    type VARCHAR(50) CHECK (type IN ('ingresos', 'salidas', 'cables')),
    signature_columns TEXT[] NOT NULL, -- array of columns used to auto-identify the file type
    required_columns TEXT[] NOT NULL,  -- mandatory columns (e.g., TRANSACTION KEY)
    column_mapping JSONB NOT NULL,     -- e.g., {"TRANSACTION KEY": "key", "CantRecep.": "cantidad"}
    created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);
```

### Proposed UI flow (Steps)
1. **Paso 1: Carga:** User drops any spreadsheet.
2. **Paso 2: Mapeo de Columnas (NEW):** 
   - Displays system fields on the left (e.g., *Clave de Transacción*, *Cantidad*, *Fecha*).
   - Renders dropdowns on the right populated with headers detected from their uploaded Excel.
   - Saves mappings as a custom profile so they don't have to map it again next time.
3. **Paso 3: Validaciones:** Runs matching pipeline using dynamic mappings.

## 2. Cable Scheduling Manager
A dedicated view/section to manage the import, tracking, and consumption of cables from **Cable Scheduling Sheets**.

### Objectives
- Upload a Cable Schedule spreadsheet containing detailed cable runs (Cable Tag, Type, Length, Source, Destination).
- Extract and track the status of each cable run (e.g., *Disponible*, *Tendido*, *Conectado*).
- Track drum stock consumption dynamically.

### Proposed Database Schema (`cables_schedule`)
```sql
CREATE TABLE cables_schedule (
    cable_tag VARCHAR(100) PRIMARY KEY,
    tipo_cable VARCHAR(100) NOT NULL,
    longitud_diseno NUMERIC(10, 2) NOT NULL,
    longitud_tendida NUMERIC(10, 2) DEFAULT 0,
    origen VARCHAR(255),
    destino VARCHAR(255),
    estado VARCHAR(50) DEFAULT 'Pte Tendido' CHECK (estado IN ('Pte Tendido', 'Tendido', 'Conectado', 'Omitido')),
    drum_number VARCHAR(100), -- tracks which drum the cable was taken from
    created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);
```

### Core Features
- **Smart Cable Importer:** A specialized wizard step inside the sidebar navigation that auto-detects Cable Scheduling columns (e.g., matching signatures like `Cable Tag`, `From`, `To`, `Length`).
- **Tendido Progress Tracker:** Quick buttons to update a cable's state from `Pte Tendido` to `Tendido` or `Conectado`, logging the quantity of meters cut from stock.
- **Drums (Carretes) Stock Integration:** Link cable cuts to active drums inventory so that drum lengths are automatically calculated and deducted.
